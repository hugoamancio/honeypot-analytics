# ============================================================================
#  Cowrie - quais credenciais "funcionam"
#
#  Copiar para  ~/cowrie/etc/userdb.txt  no servidor.
#
#  POR QUE ISTO IMPORTA MAIS DO QUE PARECE
#
#  A configuracao de fabrica do Cowrie aceita praticamente qualquer senha.
#  Isso denuncia o honeypot na hora: nenhum servidor real aceita
#  root/qualquercoisa, e bot bem escrito testa exatamente isso - manda uma
#  senha aleatoria improvavel e, se entrar, sabe que e armadilha e sai.
#
#  Aceitando so um conjunto pequeno de senhas comuns, o comportamento fica
#  igual ao de uma maquina real mal configurada: a maioria das tentativas
#  falha, e de vez em quando uma acerta.
#
#  FORMATO
#      usuario:x:senha         aceita exatamente essa senha
#      usuario:x:!senha        REJEITA essa senha especificamente
#      usuario:x:*             aceita qualquer senha (nao usar)
# ============================================================================

# ---------------------------------------------------------------------------
#  root - as senhas que realmente aparecem no topo de qualquer honeypot
# ---------------------------------------------------------------------------

# Rejeitadas de proposito ANTES do curinga: sao as duas primeiras que um
# scanner de honeypot testa justamente por serem obvias demais.
