Texto do post

Meu código funcionava. Rodei o mesmo arquivo duas vezes e descobri que ele duplicaria dados em produção todas as madrugadas. Estou construindo um sistema de detecção de intrusão sobre um honeypot — um servidor isca que finge ser um SSH mal configurado para registrar quem tenta invadir. O pipeline controlava duplicata por hash do arquivo. Parecia suficiente. Reprocessei o mesmo log e a tabela de tentativas saltou de 5.916 para 11.832 linhas. A causa não era o teste. O log de um honeypot cresce durante o dia: o hash muda, o arquivo passa pela checagem, as sessões antigas voltam no processamento e são gravadas de novo. Duplicaria todo dia, em silêncio, e eu só perceberia quando algum número não fechasse. Corrigi movendo a garantia para o banco — uma chave natural — em vez de deixá-la numa checagem no Python. A diferença importa: regra que depende de alguém lembrar de aplicar não é garantia, é torcida. Esse foi um de três bugs que encontrei. Nenhum deles gerava erro. Todos rodavam perfeitamente mostrando a coisa errada, que é o tipo de defeito mais perigoso que existe. O que o projeto tem hoje: → PostgreSQL modelado: 9 tabelas, 43 constraints, 30 índices — cada índice com justificativa escrita → 11 regras de detecção em SQL, mapeadas ao MITRE ATT&CK → Pipeline de ingestão idempotente em duas camadas → Dashboard de triagem de alertas Os dados ainda são sintéticos: escrevi um gerador que produz log no formato exato do Cowrie para desenvolver tudo sem depender de infraestrutura. O sensor real sobe nas próximas semanas — e nenhuma linha de código muda quando ele entrar. Passo a passo

Como capturar e publicar

  1. Nesta página, aperte Win + Shift + S e selecione um quadro inteiro. Ele já está no formato quadrado que o LinkedIn usa.
  2. Repita para o segundo quadro.
  3. Com o dashboard rodando (streamlit run dashboard/app.py), capture a tela dele também — screenshot do produto real vale mais que arte, e essa deve ser a primeira imagem do post.
  4. No LinkedIn, publique as três juntas: dashboard, depois os dois quadros. Post com imagem alcança bem mais que post só de texto.
  5. Cole o texto, confira se o link do repositório aparece, e publique.

Um detalhe de alcance: o LinkedIn reduz a entrega de posts com link externo no corpo. Se quiser maximizar, deixe o link no primeiro comentário e escreva “link nos comentários” no lugar dele. Vale a pena? Só se você quiser alcance amplo. Para ser encontrado por recrutador, o link visível é mais direto.
